# KW-7 AI — демо-версия на 30 дней

Попробуйте KW-7 AI бесплатно: чат с AI-агентами на вашей модели — облачной или
локальной. Поиск и разбор сайтов, расчёты, графики и схемы, автономное выполнение
бизнес-целей с проверкой каждой цифры по источнику.

Демо работает 30 дней с момента активации. Интеграции с корпоративными системами,
документы Word и PowerPoint, работа с базами данных и другие возможности коммерческой
версии в демо недоступны — система прямо скажет об этом, если их попросить.

**Как это выглядит:** установка → активация по почте → подключение модели → работа.
На всё уходит 15–20 минут.

---

## 1. Что понадобится

- **Windows 10/11** с [Docker Desktop](https://www.docker.com/products/docker-desktop/)
  или **Linux** с Docker Engine и `docker compose`.
- 8 ГБ оперативной памяти (минимум 4 ГБ свободной), около 3 ГБ на диске.
- Интернет.
- **Модель**: ключ облачной модели (OpenAI, GigaChat или любой сервис с OpenAI-совместимым
  API) **или** модель на своём компьютере (Ollama, LM Studio). Подробно — в разделе 4.

## 2. Установка

1. **Запустите Docker Desktop** (Windows) и дождитесь в его окне зелёной надписи
   **Engine running**. При первом запуске примите лицензию; это может занять 1–2 минуты.
   Проверка: команда `docker info` выводит сведения о сервере, а не ошибку.
2. Создайте пустую папку, например `C:\kw7-demo`, и скачайте в неё файл
   [`docker-compose.yml`](docker-compose.yml) (кнопка **Download raw file** на странице файла).
3. Откройте в этой папке терминал (PowerShell или консоль Linux) и выполните:

   ```bash
   docker compose up -d
   ```

   Первый запуск скачивает около 350 МБ.
4. Откройте в браузере **http://localhost:8080**.

<details>
<summary>Установка без доступа к ghcr.io (из архива)</summary>

1. На странице [Releases](../../releases) скачайте `kw7-demo-images-<версия>.tar.gz` и

2. В этой папке выполните:

   ```bash
   docker load -i kw7-demo-images-<версия>.tar.gz

   ```

## 3. Активация

1. На экране активации укажите рабочую почту, придумайте пароль администратора
   (логин — `admin`) и примите согласие на обработку данных.
2. Введите код из письма — он действует 30 минут. Письма нет? Проверьте папку «Спам».
3. Войдите под `admin` с вашим паролем.

Одна почта — одна установка.

## 4. Подключение модели

Модель — это «мозг» системы; без неё чат не отвечает. Подключите **один** из вариантов.

Все настройки — в админке: **http://localhost:8080/admin/**, вход под `admin`.

### Вариант А. Облачная модель (OpenAI и совместимые)

1. Получите ключ API у провайдера (например, на
   [platform.openai.com/api-keys](https://platform.openai.com/api-keys)).
2. В админке откройте **«Облачные модели»** → **«Добавить»** (справа вверху).
3. Заполните:

   | Поле | Что вписать |
   |---|---|
   | Название | любое, например `OpenAI` |
   | Активная | ✔ |
   | Ключ доступа (API key) | ваш ключ |
   | Модель | `gpt-4.1` (или другая модель провайдера) |
   | Адрес API (Base URL) | `https://api.openai.com/v1` (для другого провайдера — его адрес, обычно оканчивается на `/v1`) |

   Остальные поля не меняйте.
4. Нажмите **«▶ Проверить подключение к LLM»** внизу страницы — должен появиться
   успешный ответ модели. Затем **«Сохранить»**.

### Вариант Б. GigaChat

1. В [личном кабинете GigaChat](https://developers.sber.ru/studio) создайте проект и
   скопируйте **ключ авторизации**.
2. В админке: **«Облачные модели»** → **«Добавить»** (справа вверху):

   | Поле | Что вписать |
   |---|---|
   | Название | `GigaChat` |
   | Активная | ✔ |
   | Ключ доступа (API key) | ключ авторизации |
   | Модель | `GigaChat-2-Max` |
   | Адрес API (Base URL) | оставьте как есть (`https://gigachat.devices.sberbank.ru/api/v1`) |
   | Scope | `GIGACHAT_API_PERS` для физлица, `GIGACHAT_API_CORP` или `GIGACHAT_API_B2B` для организации |

3. **«▶ Проверить подключение к LLM»** → **«Сохранить»**.

### Вариант В. Модель на своём компьютере (Ollama)

1. Установите [Ollama](https://ollama.com/download) и скачайте модель:

   ```bash
   ollama pull qwen3:14b
   ```

   Для работы с агентами нужна модель с вызовом инструментов (tool calling) — подойдут
   Qwen3 от 14B. Чем больше модель, тем лучше результат и тем выше требования к
   видеокарте.
2. В админке: **«Локальные модели»** → **«Добавить»** (справа вверху):

   | Поле | Что вписать |
   |---|---|
   | Название | `Ollama` |
   | Активная | ✔ |
   | Адрес сервера (Base URL) | `http://host.docker.internal:11434/v1` |
   | Модель | `qwen3:14b` (точно как в `ollama list`) |
   | Ollama (нативный API) | оставьте **выключенным** |
   | Ключ доступа (API key) | `ollama` |

3. **«▶ Проверить подключение к LLM»** → **«Сохранить»**.

**LM Studio** — то же самое: в LM Studio загрузите модель и включите сервер
(вкладка **Developer** → **Start Server**), адрес `http://host.docker.internal:1234/v1`,
ключ `lm-studio`, модель — как она названа в LM Studio.

### Включите выбранный тип модели

Вернитесь на http://localhost:8080, откройте справа вкладку **«Агенты»** и в переключателе
модели выберите **облачную** (варианты А, Б) или **локальную** (вариант В).

То же можно сделать в админке: **«Активная модель: облачная или локальная»** → запись в
списке (или **«Добавить»**, если список пуст) → поле **«Режим»** → **«Сохранить»**.

Готово: задайте вопрос в чате.

## 5. Что попробовать

- **Кнопки готовых отчётов** на главном экране: сводка новостей с сайтов, курс валют ЦБ
  за месяц с графиком, расчёт с формулами и графиком, 3D-поверхность, схема процесса.
- **Вкладка «Цели»** — пример бизнес-цели: система сама планирует работу, ищет данные в
  интернете и пишет обзор, где у каждой цифры есть ссылка на источник.
- **Свой вопрос** — например: «Сравни курс доллара и юаня за последний месяц и построй
  график».

## 6. Если что-то не работает

| Что видите | Что делать |
|---|---|
| `failed to connect to the docker API … dockerDesktopLinuxEngine` | Docker Desktop не запущен. Запустите его и дождитесь **Engine running** |
| `port is already allocated` | Порт 8080 занят. Запустите на другом: `$env:KW7_PORT=8090; docker compose up -d` (PowerShell) или `KW7_PORT=8090 docker compose up -d` (Linux), откройте http://localhost:8090 |
| Чат не отвечает или пишет об ошибке модели | Проверьте модель в админке кнопкой «▶ Проверить подключение к LLM» и что она выбрана в «Активная модель» |
| Локальная модель не отвечает | Убедитесь, что Ollama или LM Studio запущены, а в адресе стоит `host.docker.internal`, а не `localhost` |
| Агенты не вызываются, модель только отвечает текстом | Модель не поддерживает вызов инструментов — возьмите другую (GPT-4.1, GigaChat-2-Max, Qwen3 от 14B) |

Не помогло — напишите на **support@kw-7.ru**.

## 7. Обновление и удаление

```bash
docker compose pull && docker compose up -d   # обновить, данные сохраняются
docker compose down                           # остановить
docker compose down -v                        # удалить вместе с данными
```
