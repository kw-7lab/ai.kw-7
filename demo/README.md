# KW-7 AI — демо-версия на 30 дней

Бесплатная версия KW-7 AI для знакомства: чат с AI-агентами, подключение к облачной или
локальной модели, веб-поиск и разбор страниц, графики, схемы, расчёты в изолированном
исполнителе кода, автономное выполнение бизнес-целей с журналом проверенных фактов.

Демо работает 30 дней с момента активации. Возможности коммерческой версии (Jira,
Confluence, Tempo, почта, документы Word и PowerPoint, SQL, терминал, разработка плагинов
и другие) в демо недоступны — система прямо скажет об этом, если их попросить.

## Что понадобится

| | |
|---|---|
| Система | Windows 10/11 с [Docker Desktop](https://www.docker.com/products/docker-desktop/) или Linux с Docker Engine и плагином `docker compose` |
| Память | от 4 ГБ свободной оперативной памяти (рекомендуется 8 ГБ) |
| Диск | около 3 ГБ |
| Интернет | для активации, проверки лицензии раз в 6 часов работы, веб-поиска и облачной модели |
| Модель | ключ облачной модели с OpenAI-совместимым API (в том числе GigaChat) **или** локальная модель (Ollama, LM Studio) |

Без связи с сервером активации демо продолжает работать до 7 суток работы.

## Установка

### Вариант 1. Из реестра (рекомендуется)

1. Скачайте файл [`docker-compose.yml`](docker-compose.yml) в пустую папку, например
   `C:\kw7-demo` или `~/kw7-demo`.
2. В этой папке выполните:

   ```bash
   docker compose up -d
   ```

   Первый запуск скачивает около 350 МБ и занимает несколько минут.
3. Откройте в браузере http://localhost:8080.

Порт занят? Запустите с другим: `KW7_PORT=8090 docker compose up -d` (Linux) или
`$env:KW7_PORT=8090; docker compose up -d` (PowerShell).

### Вариант 2. Без доступа к реестру (архив)

Если `ghcr.io` недоступен из вашей сети:

1. Скачайте со страницы [Releases](../../releases) архив `kw7-demo-images-<версия>.tar.gz`
   и файл `docker-compose.yml`.
2. Загрузите образы и запустите:

   ```bash
   docker load -i kw7-demo-images-2026.10.19.tar.gz
   docker compose up -d
   ```

## Активация

При первом открытии http://localhost:8080 появится экран активации:

1. Укажите рабочую почту и придумайте пароль администратора (логин — `admin`), примите
   согласие на обработку данных.
2. На почту придёт код — введите его. Код действует 30 минут.
3. Войдите под `admin` с заданным паролем.

Ключ привязан к этой установке и действует 30 дней. Одна почта — одна установка; повторная
активация той же установки срок не продлевает.

## Подключение модели

Откройте админку http://localhost:8080/admin/ (пользователь `admin`).

**Облачная модель** — раздел «Облачные модели» → «Добавить»: адрес API
(OpenAI-совместимый, например `https://api.openai.com/v1`; для GigaChat — адрес Сбера),
ключ и название модели.

**Локальная модель** — раздел «Локальные модели» → «Добавить»:
- Ollama: адрес `http://host.docker.internal:11434/v1`;
- LM Studio: адрес `http://host.docker.internal:1234/v1`;

название модели — как в Ollama или LM Studio (например, `qwen3:14b`). Отметку
«Ollama (нативный API)» оставьте выключенной: адреса выше — OpenAI-совместимые.

Затем в разделе «Активная модель: облачная или локальная» выберите, какую использовать.
Переключать модель можно и в самом чате, на вкладке «Агенты».

Для работы с агентами нужна модель, которая умеет вызывать инструменты (tool calling):
например, GPT-4.1, GigaChat-2-Max, Qwen3 от 14B.

## Что попробовать

На главном экране есть кнопки готовых отчётов — с них удобно начать:
сводка новостей с сайтов, курс валют ЦБ за месяц с графиком, расчёт траектории с
формулами и графиком, 3D-поверхность, схема процесса, шпаргалка с формулами.

На вкладке «Цели» — пример бизнес-цели: система сама планирует задачи, ищет данные в
интернете, проверяет каждую цифру по цитате из источника и пишет итоговый обзор.

## Обновление и удаление

```bash
docker compose pull && docker compose up -d   # обновить, данные сохраняются
docker compose down                           # остановить
docker compose down -v                        # удалить вместе с данными и ключом
```

## Данные

Всё, что вы загружаете и обсуждаете в чате, хранится только у вас — в томе `kw7_data`.
На сервер активации уходят только данные формы активации и код установки при проверке
лицензии. Запросы к модели уходят туда, куда вы её подключили: в облако провайдера или на
вашу машину. Веб-поиск и чтение страниц идут из контейнера напрямую к поисковикам и сайтам.

Политика обработки персональных данных: https://kw-7.ru/privacy
